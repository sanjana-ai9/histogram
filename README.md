# Day 27 - Histogram Analysis

## Internship
AI & ML Internship – Veda Technology

## Objective
To create a histogram for numerical data and understand the distribution of values.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Description
In this task, I created a Student Marks Dataset using Pandas and visualized the distribution of marks using a histogram.

The histogram helps to understand how student marks are distributed across different ranges.

## Observations
1. Most students scored between 50 and 90 marks.
2. The marks are distributed across different ranges.
3. Very few students scored at the extreme ends.

## Outcome
Successfully created a histogram and understood the distribution of numerical data using Python and Matplotlib.
